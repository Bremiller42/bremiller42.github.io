Noesis

Python · Ollama / LM Studio / llama.cpp · ChromaDB

A self-hosted local AI assistant that runs entirely offline — no cloud API required. Built around a tool-calling agent loop with persistent vector memory, subagents for specialized tasks (coding, debugging), and support for multiple LLM backends including GPU-quantized llama.cpp inference. Includes a custom orchestration layer that decomposes each user turn into intent and constraints before generating a response, and integrates with Telegram and a web chat UI. Currently private while still in active development.
